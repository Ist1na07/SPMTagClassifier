# 交付结论：保留局部专家，改进整谱负担聚合

采用 **一阶多分支支持 + 连续负担积分 + 冻结旧判断先验的门控**。有 SPM Rating 时推荐 Detailed；Compact 使用自己的同族配置。无评分输入运行独立动作版，不额外评分。新增接口和插件适配器已进入 v1.3.0。

口径：原349条整谱标签、原权重、6个源歌曲／重复物理谱外折；每折只用其TRAIN（等价于汇总原3个INNER验证库存）重选所有活跃参数。最终共同配置只读汇总INNER评分，随后才做共同配置重放。归档专家的历史训练暴露未知，这批资料也已经被反复研究，属于**回顾性分组对照**，不是新的盲测。

主要收益是把有实质负担的 RC／LN 混合谱识别为 Hybrid，而不再错误要求三个细类。低支持类型不再只靠持续时间挤进整谱 tag。总体指标同时上升，但逐类仍有退步；下面保留完整 P/R/F1。

局部头、Break／family路由、可见局部主类与BPM全部保留。新的整谱指标不能算作局部分段准确率提高。Tech→Dense CS、非典型LN的原型贴合与缺少Anchor分支支持仍未解决。人工对照 B02、C24、I01/I02 等存在误判，不能把整体均值上涨解释为这些动作都已学会。

## 先定模型，再联调参数

`P(c)=100*integral(s_c(t)*w(t))/integral(w(t))`。多分支可重叠；`w=log1p(D)^alpha * log1p(A)^beta`，A同时包含头／并集尾的方窗动作率和区间并集持键量。Break支持为零但负担留在分母。评分场采用原生行时钟的右连续重建；不取逐行简单平均，不重复调用评分器。

保留旧整谱结果作为冻结先验，用新份额进行保留／剔除、增加和强原型替换Mix；两大家族达到实质负担阈值即可Hybrid。全部修正关闭时回到v1.2.2 tag集合。与重新拟合一个自由分类头相比，这保住了有限样本中仍有用的成熟经验。具体公式与API见[使用说明](../../docs/perception.md)。

### 消费验收否决平方支持，而不是挑最高历史分数

R2在允许支持度平方时，Compact共同配置使25张原本有tag的输入失去全部实心主类。专家分数本身不是校准概率，平方后再沿用份额门控没有稳定的贴合度解释；因此最终明确约束为一阶支持。用已完成的完整R2笛卡尔表，重新联合选择**所有其他参数**；没有新拟合、没有扩大网格。

这项限制是在看到消费反例后作出的，已写入`linear-support-r3/protocol.json`。上表是这个明确约束下的回顾性重新选择结果，不能称为预注册盲测。它把原Compact的25例抑制缩到2例；剩余未定输出在UI如实显示，不强行补标签。

R1早期组合的macro-F1曾达到55.34%；扩大活跃边界后的R2回落，一阶交付配置的Detailed为54.43%。没有从已经看过的外折里挑最高历史分数发布，也没有把网格边界包装成全局最优。

### 最终配置与参数平地

动作版：`alpha0,beta2,window1000ms,hold1,power1`；保留阈值.25，增加阈值.5，不用强原型替换旧Mix；Hybrid的RC/LN阈值.10/.05。

Detailed／Compact：`alpha4,beta1.5,window1000ms,hold1,power1`；保留阈值.25，不新增旧判断外的独立细类；Hybrid阈值.07/.05。Detailed的强原型替换阈值.5；Compact关闭该替换。

R2完整域为125套权重、硬时间和一／二阶支持共251表示，82家族策略、336细类策略；每外折比较6,915,552个函数。没有把这些枚举称作数值优化拟合次数。最终一阶限制保留其中硬时间与125个一阶表示，所有家族／门控仍联合比较。

选择目标为.5macro-F1+.25micro-F1+.25sample-F1，INNER同时要求macro P/R/F1和micro不低于冻结基线；该约束不能保证OUTER不退步。近最优0.1个百分点内优先线性物理解释、1秒窗、持键信用和更少修正，是明确先验。

条件剖面固定一个坐标、重选其他全部参数，同时记录实际预测向量变动和百分数变化；并非只看目标值是否平坦。详见两个R2目录的`conditional-profiles.json`。一些门控是功能平地，alpha仍在上边界，不能宣称所有参数都已进入唯一稳定的井；保持有明确物理定义、受范围约束的配置，按本轮预算停止扩域。

## 完整消融与未采用的路线

1. `integral-r1`：硬时间、分支时间、难度、物量、联合、组件，各自完整联调权重／ridge／平衡；23,544个数值fit。自由细类头没有形成全面收益。
2. `hierarchy-r2`：分开建模整谱Mix与细类；47,088个fit。Rbar总是伴随总需求及P/C/J角色对照，避免把高难Density误当Release。组件路线没有提供可靠净收益，生产版未引入额外组件计算。R1的数值缺陷和不完整结果另外保留，不并入R2。
3. `threshold-r1`：直接份额阈值、TRAIN全部有限分割与收缩、家族混合判定联合枚举。单靠重新拟合自由阈值不够稳定。
4. `anchored-r1/r2`：保留成熟判断，联合选择权重和门控；包含Hybrid关闭、硬时间、软分支时间、难度、物量和二者联合。Compact独立使用同一完整域。
5. `linear-support-r3`：消费反例驱动的一阶限制；每项消融都从完整已算表重新选择其余活跃参数，完整逐外折选择、OUTER预测及共同重放分别归档。
6. `joint-r1`：整谱标签经积分反传到已有局部分支的受限残差，原349整谱／6条人工分段，432配置×6外折×3内折，双起点。原型为零的分支和family路由固定，不能学出缺失分支。实际2035/2592配置检查点（6105/7776内层fit）完成，4个外折完整；另有模型投影梯度0.000117449高于1e-5，未通过收敛验收。**未完成、不发布完整外折指标、不采用局部修正**；保留检查点与独立梯度核对记录。本轮不再为此追加搜索时间。

完整消融数表见各目录`REPORT.md`；最终一阶约束的全部对照见下一节。

## 交付验收与证据位置

- `final-runtime/parity.json`：全部411输入、3套最终配置、17,262个百分数与Python逐项比较；最大误差约2.43e-12个百分点。8,483个自然原始段核对，局部可见主类／时钟／BPM与classic相同。

- `final-runtime/overlay-check.json`和PNG：真实上游渲染器的离线430px页面，复用原始难度、切换评分模型、平滑不变性、真实图DT时钟和300BPM回归。插件评分数值在有／无新证据选项时相同。未接入用户实时游戏或tosu。
- npm测试、TypeScript、静态浏览器CSP路径和插件更新器的备份／重复应用／拒绝未知版本均已验收。运行时间包括一次原分类分析，不包括外部SPM评分；本机缓存全谱分析中位约39ms、P95约158ms，见receipt。

## 阅读与复用归档

大JSON按原字节gzip归档；门控完整参数评分表按唯一评分向量＋索引无损存储，保留全部组合。`archive-inventory.json`列出位置、形状和数量。展开：

```powershell
python research/perception/archive_evidence.py --unpack
node scripts/export-perception.cjs

```

大型重复表示缓存、原始优化向量和谱面不进Git；原数据／人工剪辑与本地检查点保留。重新运行数值研究需要本地dataset、原`.cache/rework7.jsonl`与原分组协议、人工对照谱，以及固定SPMRating v1.2.0环境和评分缓存。准备／提取脚本、冻结协议和所有已完成选择均在本目录；不是在无数据的新机器上一条命令即可重现。生产使用不依赖这些文件。
