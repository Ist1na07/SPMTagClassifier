# 规范化改变了分段距离的隐含权重

原生全链 25 组重调中，逻辑五修正＋中性手＋覆盖取得整谱 macro-F1 54.11%、分段按谱准确率 69.72%；原固定算法为 51.98%/69.59%。差值区间均跨零，继续研究该方向，不把它当作已经验证的提升。

把 Release 替换和分段信号归一化一起加入，分段降至 62.12%，相对原固定算法的成对区间为 −13.51 至 −1.87 个百分点。四格实验进一步将其拆开：只加归一化相对上述逻辑基础为 −3.83 个百分点［−6.35, −1.50］；只加 Release 为 −3.96［−10.32, +0.89］；两项合计 −7.60［−12.58, −2.44］。当前组合不进入默认产品。

源码给出了更具体的解释：变化点取规范化特征的平均 L1 距离。旧实现将 NPS、Jack BPM、尾速和 Cut Demand 做 log 变换，却仍除以原值分位跨度；它实际上把这些速率信号压低了。改成同域跨度不仅“更规范”，还改变了这四个信号相对其他信号的权重与截断程度。此前调了总 prominence 和最小段长，**仍未给这个新的相对权重自由度调参**；不能据此断言规范化方向无用。

下一项检验因而是低容量的分段度量收缩：在旧规范化向量与同域规范化向量之间，以 `s∈{0,0.05,0.2,1}` 插值。只改变分段信号，不混合键型标签或两个不同分类体系。两个端点复用已有缓存，中间两档重新提取；与 Release 可选尺度、边界、家族/规则门控和有效聚合同时选择。保留零强度保证有成熟校准作为可选先验，但仍要求逻辑五修正、中性手、覆盖和一致的证据消费。

这项实验应补齐同样空间下的无 Release、无度量变化、硬/分布聚合及权重消融，再决定是否采用中间度量；不能看外层最高点选择强度。四个端点的完整原生消费复现和中间向量的精确插值测试先于搜索。

另一个已确定的结论是：完整表示的 soft 组在六折均选择集中度指数 0，去集中度控制得到完全相同配置和输出。本轮没有支持“集中度加权提高效果”的证据。聚合策略重调后分段成绩的变化，来自它改变了被选中的局部门控，而非聚合函数直接改对了局部标签。

镜像群平均虽然严格满足交换视图不变性，本轮整谱/分段结果未优于原固定算法，还需要双次推理，不作为默认升级。对称性证明与玩家分类准确率是不同的验收项。

## 度量强度联调仍未解决主候选退化

16种度量/Release组合与其余流程共同选择、每项限制16,384个候选的实验已经完成。预定主池为整谱macro-F1 53.47%、分段按谱64.89%；相对原固定流程的分段差值区间为［−8.72, −0.91］个百分点，不进入默认算法。多数外层选择了0.2的度量强度；不能把端点全规范化的失败外推成所有中间权重都无效，但当前主池也未建立可采用的改善。

去Release控制为53.36%/69.70%，但检查候选身份发现：它与主池只重合2,008项，六折选中的配置都不在主池中。相同预算使两个搜索程序可比较，却不能把分差全当作只改变Release表示的效应。主池本身六折只有一折选了Release替换，进一步说明重选配置与搜索覆盖都在起作用。

因此先固定所有已计算预测，按真实内层验证选择流程更新容量；再把十个非历史候选池无标签合并成99,500项，从**同一个并集**筛选各限制，重做容量与整条策略选择。全池包含各控制所有可选配置，不另抽控制组候选。见 `POLICY_CAPACITY.md`、`NATIVE_UNION.md`。这一修订不重复专家训练或特征提取，也不在外层挑最好的一组当主算法。
