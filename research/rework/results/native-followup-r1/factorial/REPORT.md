# 分段信号归一化与 Release 替换：四格重调比较

每格均在同一六折歌曲组/精标留一协议下，重新选择完整原生分段、门控、显示与聚合。Release 的 20/40/80 ms 只在内层选。三格复用已有有效结果，补做唯一缺失的“只改分段信号归一化”格。

| 条件 | 整谱 macro-F1 | 分段按谱等权 | 分段按时长 |
|---|---:|---:|---:|
| 逻辑修正＋中性手＋覆盖 | 54.11% | 69.72% | 69.04% |
| 再加 Release 替换 | 52.62% | 65.76% | 66.06% |
| 再改分段信号归一化 | 52.16% | 65.88% | 64.41% |
| 两项都加 | 52.35% | 62.12% | 61.31% |

| 成对差值 | 整谱百分点［95%区间］ | 分段百分点［95%区间］ |
|---|---:|---:|
| release_minus_base | -1.49 [-6.71, +0.98] | -3.96 [-10.32, +0.89] |
| scale_minus_base | -1.95 [-7.15, +0.46] | -3.83 [-6.35, -1.50] |
| both_minus_base | -1.76 [-7.36, +0.54] | -7.60 [-12.58, -2.44] |
| scale_given_release | -0.27 [-2.64, +1.33] | -3.64 [-9.55, +2.97] |
| release_given_scale | +0.19 [-2.42, +2.13] | -3.76 [-8.76, +0.61] |
| interaction | +1.68 [-1.59, +6.66] | +0.20 [-5.24, +6.40] |

归一化修改作用于变化点使用的分段信号，不直接替换固定边界上的 56 项分类向量；输出差异因此包含边界改变及重新选择的门控/聚合。Release 替换改变一个 LN 表示的含义，冻结原系数的比较不能代替重新训练该表示。

这是两个方案经重调后的差值，不是把其他阈值锁死的单一微分效应。交互为“两项都加−只加释放−只改归一化＋基础”；整谱区间按歌曲组、分段区间按六张人工谱成对抽样。完整逐谱、混淆与所选配置见 `metrics.json`。
