## 问题与预先确定的验证顺序

1. **恢复可研究的完整原流程**：原始 56 项特征、RC/LN 专家、规则、Break 门控、分段和聚合。研究接口只暴露内部数据，不改原归档文件；先证明暴露接口不改变原输出。
2. **先定位下降来源**：比较原分段、人工边界、旧预测两秒量化、错误时长、类别与门控；检查新模型缺少的相对谱面上下文，而不是只扩大已有网格。
3. **计算修正逐项处理**：LN 区间重复面积、头/尾邻接、同刻尾头、节奏相位、tail independence 等分别有精确反例。固定旧系数的结果是协变量变化诊断，不冒充重新调参后的算法结论。
4. **同等训练条件比较完整特征**：必须包含原完整 56 项及其派生表示，不能再把旧窗口统计量叫作完整旧特征对照。弱图级标签不得无条件作为每个窗口的精确真值。强/弱监督比例和上下文进入联调。
5. **真实同链联调**：同一局部头、同一分段置信度进入最终聚合；所有局部参数选择以最终任务目标为依据，不能先用另一个局部代理指标淘汰候选。平滑、Break/RC/LN 门控及聚合与头部参数的耦合要有联合对照。
6. **重新拟合的消融**：原版、只修逻辑、加上下文、替换/增加特征、变更监督、变更聚合、最终组合各自重拟合、重选择；报告正负结果和每张谱/每类的变化。结构修正与模型重训的作用分开。

## 评价与防止选择偏差

- 现有数据已经参与开发。重做采用按歌曲/重复谱分组的外层交叉验证，内层选择参数；称为回顾性分组交叉验证，不声称取得全新独立测试集。
- 记录每个外层折实际未参与拟合与选择的数据、弱/强样本权重和每个参数组合；原版历史训练暴露未知，原系数作为既有先验的比较单独标识。
- 整谱保留完整多标签口径；分段同时看按谱面等权及按时长加权结果，接受人工备选标签。额外给边界邻域和内部区间结果以区分分段与分类。
- 计算能算出的基线与反事实：上一轮两秒网格的 oracle 准确率上界 94.93%；原预测同网格量化仅从 68.92% 降至 68.31%，不能据此把 48.03% 主要归因于分辨率。
- 不预设正结果，不按测试效果挑种子，不把每次阈值评分当成独立模型或有效新贡献。

## 已定位的耦合，不把合理性当作效果

完整原入口的暴露接口在 399 条主集/精标记录上逐值一致。六谱的原预测准确率为 68.921%（将未覆盖的 37.5 ms 计错）；给定人工边界后为 74.339%。两秒网格不是上一轮下降到 48.028% 的主因。

“头部邻接跳过纯面尾行”有精确反例支持。固定原自动分段时，该修改将准确率升至 69.575%；重新自动分段却降到 67.049%。这把问题定位到**特征同时控制分类和分段**的耦合，不能据此抛弃修正，也不能直接上线。

面积积分、同刻尾/头、BPM 相位及无头持键窗口的修正目前没有改变六谱自动输出；这说明六谱对这些问题的效果识别力有限。Release isolation 的 40 ms 版本只是替代特征探针，尚未完成尺度选择。固定系数的逐项结果和完整轨迹在 `results/diagnosis.json` 与各谱 trace 中。

## 第一阶段：固定原分段，真正联调同一条概率链

`extract.cjs` 提取原完整 56 项、修正后的同名表示、新 40 项，以及谱内相对负荷上下文。各表示使用**同一组原自动边界**，避免再次同时更换所有模块。

`mil.py` 的局部头对每个真实段落输出 16 类分布（含 Break、wildcard 与可由整谱弱标签研究的 anchor）。同一分布进入 `时长 × effort^a × concentration^b` 聚合；concentration 为 `Σp²`，是分布集中度，不是正确概率。整谱细类头只对**同名键型组成**作单调校准，避免自由跨类矩阵把局部标签当成任意隐变量。Mix 头使用组成的熵、前三占比和 RC/LN 平衡，不再另读原始特征池。

强监督按预测段落与人工区间的真实重叠计算可接受标签集合的负对数似然，每张谱总权重相同。弱整谱标签通过最终整谱损失反向传播，不复制给每一个局部段落；另设复制标签和仅强监督消融。原模型作为先验的版本，与完全从当前训练折拟合的版本分别报告。

初版 MIL 探索在打开外层预测前被反例叫停：仅归一非 Break 组成，会使全谱局部都选 Break、整谱却凭微小残差自信选出细类，而且整谱损失对 Break 门控没有梯度。两个回归反例均在 r1 失败。r2 增加“非空整谱标注意味着至少一处有效段落”的 max-MIL 观测，保留非 Break 组成用于短难段/长休息谱面的解释；若所有局部主标签仍为 Break，就返回空整谱结果，不能强行 argmax 补一个标签。两个反例在 r2 通过。r1 的停止记录保留在 `results/mil-stage1/STOPPED.json`，不把未完成的搜索包装成成果。

`search.py` 在外层六折分组测试中，逐折进行内层三折选择。每个外层恰留一张精标谱；内层让其余五张均获得一次未参与拟合的预测。**全部**局部正则 × 整谱正则 × 强监督比例 × effort 加权 × 集中度加权组合都拟合，并与细类/Mix 阈值交叉评分；不先按局部代理目标筛选头部。内层选择目标为整谱 macro-F1 与按谱等权分段准确率的等权平均，同时保留两个原始轴。

增加仅偏置、上下文残差与完整特征残差三种先验适配容量，检查六谱强监督是否足以支持更大的更新。另有 `composition.cjs` 的独立数学探针：相同的全谱组成熵，可能来自每一段都不确定，也可能来自不同段落各自很确定；用 `H(平均分布)−平均H(局部分布)` 区分这两者。目前这个指标尚未接入第一阶段模型，不能提前声称提高 Mix 分类。

这一阶段只判断表示、先验、监督和聚合的相互作用。自动分段参数及 Release isolation 尺度仍须后续联调，不能把本阶段叫成完整算法升级。

复现：

```powershell
node --test research/rework/lab.test.cjs
node research/rework/diagnose.cjs
node research/rework/extract.cjs
python -X utf8 -m unittest discover -s research/rework -p test_mil.py

```

## 已完成的探索与下一项实验

- **镜像对称性**：原完整流程在 399 条记录中有 45 条镜像后整谱标签改变。交互特征把中键/左右均衡行硬算成左手；`neutralHands` 把它们作为中性行处理后，同批记录的整谱和分段标签镜像差异均为零。固定旧系数时精标准确率没有随之提高，修正需要与分段/分类重调。见 `results/mirror-audit*.json`。
- **Anchor**：4K 子桶分组嵌套调参和六项消融完成，连续单指 run/集中度有解释价值，但现有桶名不是 Anchor 属性不存在的可靠负例，7K 阳性也只来自一个组。不新增缺乏证据的硬类别。见 `results/anchor/REPORT.md`。
- **固定边界联合模型 r2**：完整网格结果、实际模型及逐谱概率已经保存，见 `results/mil-stage1-r2/REPORT.md`。训练审计证明固定预算拟合仍会明显移动，且两个 detached 控制组的线搜索目标不匹配，因此先重做训练内优化再做内层选参。停止规则、复用条件和反例说明见 `results/OPTIMIZATION.md`；r2 不作为最终模型结论。

r3 保持同一联合网格和划分，按训练梯度或连续的训练目标/预测稳定检查停止。两个无弱标签反传控制组先拟合其明确的局部目标，冻结后拟合整谱头；它们的配置仍由最终内层任务联合选择。新增拟合保存本地模型检查点，达到相同梯度条件的有效旧拟合直接复用：

## 原生流程与原结构重拟合

原生分段器、家族/规则门控、显示、负荷与聚合的 25 组联合校准已完成，每组使用预先声明的 8,192 个不重复联合候选，不是穷尽笛卡尔积。原专家系数冻结，不能把这些比较说成冷启动重训。完整结果与实际逐谱输出见 `results/native-joint-r1/REPORT.md`，空间见 `NATIVE_STUDY.md`。

完整组合没有通过：分段按谱准确率 62.12%，原固定算法为 69.59%。逻辑五修正＋中性手＋覆盖为 69.72%，差值区间跨零。补齐缺失因子格后，分段信号归一化相对该逻辑基础降低 3.83 个百分点；源码核对发现它还改变了四个速率信号在 L1 分段距离中的隐含权重，原生搜索尚未调这个自由度。下一项用低容量度量收缩，与其余流程参数同选，而非仅因数学形式更规范就上线。见 `NATIVE_FINDINGS.md` 与 `results/native-followup-r1/factorial/REPORT.md`。

`family.py` 保留原双专家与规则/Break 结构，并允许替换头部。在 399 条记录上用归档权重复现完整原生消费后，`family_search.py` 从每个训练折重新估计标准化与权重，比较源风格复制、等谱复制、bag 监督及原/修正表示；所有 30 个专家配置交叉最终门控和聚合，不先作局部筛选。实验驱动 r1 曾因原生缓存索引误用于单分区包装而在选择前失败；保留停止记录，r2 修复并在每次拟合后立即保存模型。其科学范围仍是固定原边界，不能合并其他实验的优点冒充已测试过的原生冷启动算法。训练来源审计见 `PROVENANCE.md`。

## 4K、共同粗层与真实 6K

`physical.cjs` 在原生列数上构造共同表示；已提取全部 1,748 条 4K/7K/精标记录，未出现特征提取错误。`coarse_data.py` 找到七个跨键数歌曲组，联合分组后有 1,315 条 4K 与 244 条可确定粗类的 7K 弱标签。`coarse_model.py` 让同一局部输出进入整谱，两个聚合指数与头部一同训练；`coarse_search.py` 在完整声明的离散网格中交叉拟合、选择。先跑独立 4K 基线，再复用其有效拟合进入共同模型与消融。设计、实际资源试跑及标签限制见 `COARSE_STUDY.md`，分组见 `results/coarse-data/audit.json`。

6K 的 2,344 条记录只有难度标签。`six-extract.cjs` 检查真实六列上的有限值、区间和持键状态，不用投影代理或数学对称性冒充真人准确率。它复用同一物理表示，预测无需真值标签；共同模型与最终 6K 运行检查仍须接续完成。

目前产品默认路径与已发布标签未替换。完成固定边界、冻结先验或一次试跑都不等于完成原生冷启动、4K/6K 研究、实现与发布。

## 最新证据与正在检验的方向

固定分段 r4 已处理 r3 剩余24项预算耗尽拟合，重新联合选择后66项外层配置均未改变。实际停止状态与复用依据见 `results/OPTIMIZATION.md`、`results/mil-stage1-r4/`。相同349条弱训练集的人工暴露控制，充分优化后六谱重代入73.74%、逐张留出49.09%；这是暴露诊断，不是泛化提升，见 `PROVENANCE.md`。

分段度量主池本轮外层按谱准确率64.89%，不能替换原固定69.59%的默认。完整11项限制仍在同预算联调，主池不从外层最高消融中另选。下一项固定这些预测，用额外内层验证选择**可改变多少流程参数**，再在外层训练组联合选择整条策略；不再无限扩大特征或候选空间。预定规则见 `POLICY_CAPACITY.md`。

实际6K镜像检查还找到释放顺序在同时尾端点上的列排序歧义。已修复、迁移并逐值审计缓存；共享模型改在修复表示上继续，受影响拟合重训，未变输入的1,801项拟合保留。Release整谱研究也重调了全部受影响表示并扩展共同正则范围：最新 `results/release-impression-r5/` 的11,232项不同配置/折拟合中，原56拼接新几何仍降低macro-F1（69.53%→64.27%，差值组区间−11.3至−0.4个百分点）。梯度恢复和续跑重复记录的完整审计随结果保存，重复不计作独立证据。具体修复、真实JS/Python消费及6K运行合同见 `COARSE_STUDY.md`。
