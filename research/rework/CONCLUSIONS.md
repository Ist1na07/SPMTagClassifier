# 回炉结论：采用原生粗分类，保留成熟的默认 7K

这次研究修正了早期“新特征不如旧算法”的简单归因，也补上了实际的参数联调。产品采用重新验证的 4K 五类模型和 4K/7K 共同表示的原生 6K 模型；7K 默认保留成熟决定，提供新的几何证据，完整联调的 LN 小幅更新作为显式 `modern` 候选。

## 为什么早期候选会下降

**局部目标、最后任务和监督含义没有对齐。** v1.2.0 先按局部代理目标选头，再调整谱参数，遗漏了头与后处理的耦合；旧对照也没有覆盖完整 56 项特征、双专家与规则路径。弱整谱印象不能直接复制成每一段的真值。回炉的共同粗层让同一局部分布进入时长、负荷、集中度加权及整谱组成，不再另设自由的原始特征整谱头。

**既有先验与从零重训不能混称为公平的泛化竞赛。** 完整原结构的冷重训也没有恢复归档成绩。在同一组 349 张弱训练谱下，充分优化后的人工六谱重代入准确率为 73.74%，逐谱留出为 49.09%。这说明当前资料对训练暴露非常敏感；归档系数的精确历史训练批次仍未知，不能据此断言它实际泄漏了哪些谱。见 [来源与暴露诊断](PROVENANCE.md)、[完整原结构重训](results/family-joint-r2/REPORT.md)。

**正确的局部计算不必然改善被冻结的完整流程。** 同域的分段信号归一化还改变了四个速率量在 L1 距离中的隐含权重；独立因子格中的分段变化为 −3.83 个百分点，成对区间为 [−6.35, −1.50]。扩大度量搜索、限制更新容量和修补候选池覆盖之后，预定完整候选仍没有胜过默认。见 [原生流程发现](NATIVE_FINDINGS.md)、[共同候选池](results/native-union-r1/REPORT.md)。不能把这些下降一概归为“旧缺陷其实有效”。

**Release 的一项主要漏报发生在专家之后。** 最初的小幅更新中，75.989 秒确定 Release 阳性有 59.370 秒被研究新增的头部相对负荷门控删除；旧 lowStakes 删除 5.393 秒，旧头部 Break 预标记删除 0.1565 秒。保护已经路由为 LN 的段落后，完整重选得到的主方案 Release 召回从 12.31% 升到 70.71%，精确率为 73.00%。这定位了真实门控缺陷，而不是凭头部更新无效就否定几何。见 [路由诊断](results/ln-adapter-r1/ROUTE_DIAGNOSTIC.md)、[门控独立消融](results/ln-extra-gate-r1/REPORT.md)。

优化预算也经过检查：MIL 中原先耗尽的 24 项拟合按同一停止条件续训后全部达标，66 项外层选择均未改变。不能再以“也许没收敛”解释这批已解决的负结果。见 [优化审计](results/OPTIMIZATION.md)。

## 最终采用什么

### 4K：保守五类，同一局部分布完成整谱聚合

原生 4K 的外层歌曲分组五类 macro-F1 为 **95.56%**。公开兼容标签为 `jack / stamina / speed / tech / ln`；源数据的 stamina 主要是 jump/handstream，内部称 `chordstream`，不是泛指体力属性。

整谱桶分不能代替局部语义。一个原模型夹具曾以 96.63% 支持把 120 BPM 的恒定四押连打判为 Speed，且该窗没有特征截断。新增两个固定充分条件：周期、恒定行面的纯 RC 连打属于 Jack；只有持键/释放、没有头序列的活动属于 LN。混合窗、不规则节奏、轮换和弦仍交给模型。两个开关各自消融并重新选择全部配置，不根据外层挑开关。

99 个定义级用例通过是实现合同，不是玩家标注准确率。4K 模板主方案相对同条件无模板的 macro-F1 差约 +0.14 个百分点，区间包含零，不把它包装成可靠的经验提升。见 [充分条件研究](COARSE_SUPPORT_STUDY.md)、[4K 完整结果](results/coarse-supported-all-r1/weak4_only/REPORT.md)。

### 6K：使用真实六列，不再混合投影专家的输出

采用原生列数的 53 项共同表示，包括每指负荷、节奏、持键、持续同指结构及释放几何。学习头、两个聚合指数与强弱/来源权重在同一最终任务空间联调；不填一个虚拟 7K 中键，也不把两个不相同的整谱分数加权拼成六键结果。

共享主方案在 7K **粗类**整谱上为 **92.31% macro-F1**，在可判定粗类人工区间上按谱等权为 **62.41%**。相对纯 4K 模型，分别提高 12.78 个百分点 [3.57, 26.10]、9.84 个百分点 [1.57, 19.92]。这是共享来源对迁移设计的支持，**不是原生 6K 准确率**；粗类分段分母也不同于 7K 细类评价。

实际 6K 的 2,344 张谱中，2,343 张通过完整推理、有限值、覆盖及持键检查，共 180,009 个窗口；696 个物理空窗、1,069 个无头持键窗按其真实状态处理。32 张按物量分位选取的真实镜像全部通过。时长加权的特征坐标截断比例为 0.291%，不能将其解释成识别正确率。`bm6k_0778` 的两个尾早于头 2 ms，按 `InvalidHoldTail` 拒绝。见 [真实六键最终检查](results/six-final-runtime-r1/summary.json)。

### 7K：新候选可选，成熟结果仍默认

| 流程 | 整谱 17 类 macro-F1 | 人工细类分段按谱等权 |
|---|---:|---:|
| 原固定算法 | 51.98% | 69.59% |
| LN 保护门控、原专家零更新 | 54.21% | 68.54% |
| 主候选：geometry3 小幅更新、LN 保护门控 | 54.32% | 68.75% |

主候选相对原固定算法的整谱差区间为 [−1.41, +4.82] 个百分点，分段差区间为 [−3.09, +0.58]。相对同门控零更新，整谱只增加 0.11 个百分点 [−0.60, +0.91]，分段增加 0.21 个百分点 [0.00, +0.62]。现有精标只有两个 Release 阳性谱来源；这些结果不足以替换默认。

`modern` 现在实际运行这个完整联调的候选，而不是 v1.2.0 的旧扁平研究头。默认稳定路径增加可读取的 anchor/release 几何，但不把新含义的指标硬塞给归档旧系数。Anchor 桶名不等于属性真值，新增量保留为连续描述，不创造无可靠真值的新硬类。见 [Anchor 研究](results/anchor/REPORT.md)。

## 联调和消融具体覆盖了什么

- 共同粗层：2/4/8 秒上下文、两级相对门控、三级局部正则、两级人工强度、三级来源权重；学习头与 effort/concentration 两个指数共同优化。16 项特征、监督、聚合及来源控制各自重新选择，随后四种物理模板流程完整重选，保存 107,568 项最终配置评价和 384 项外层选择。
- 26,892 是保存的“方案/折/配置”拟合轨迹身份，其中 sequence44 与 no_release 有 1,944 项相同有效训练问题；共 24,948 个不同有效问题，不是数万条独立训练样本。以后复跑复用该别名的有效拟合及预测，不再次训练同一问题。见 [有效拟合记账](results/coarse-supported-all-r1/effective-fit-accounting.json)。
- LN 更新：7 项可学习表示/删除特征控制，加精确零头。每项 30 组拟合配置完整交叉相同 512 项后处理策略；门控关闭后去除失效维度重复，保留 488 项。3,780 项辅助内层拟合用于各门控，不重复算新训练；新门控后的最终输出全部重算、重选。
- 六外层、三内层按歌曲及物理重复谱分组；同一首歌跨键数也不能跨训练/验证。主方案在打开其外层结果前确定，不从外层最高消融另挑赢家。结果是回顾性分组交叉验证。
- 测量协议固定为 10 ms 行合并、2 秒粗层输出步长；标准差下界、±6 标准化截断及优化停止阈值属于预先固定的数值约定。完整比较针对声明的有限空间，不声称所有测量约定和连续超参数的全局最优。原生 6K 没有键型真值，采用列数、时间尺度及每指量的数学外推。

完整预定主方案及成对消融图见 [共同粗层总结果](results/coarse-supported-all-r1/REPORT.md)、[成对差](results/coarse-supported-all-r1/ablation-paired-effects.json)。负结果、重复候选、停止记录和修复均保留。

## 定型模型与有效证据分开保存

发布模型只用实际内层留出预测选择：每张谱恰有五次留出预测，每次物理文件权重除以五；不投票、不从外层模型里挑一个最好者。选中后在全部允许资料上拟合一次。4K 只用 4K 目标，6K 用原共享目标，7K 候选仍联合选择全部头配置与后处理。见 [定型协议](COARSE_FINAL_SELECTION.md)、[共同粗层模型](results/coarse-final-r1/complete.json)、[LN 候选](results/ln-final-r1/complete.json)。这些全数据拟合不产生新的独立测试分数。

正式 Node API 和浏览器 IIFE 在 27 张真实 4/6/7K 谱上的完整 JSON 一致；与 Python 研究消费者的局部支持最大差约 1.45e−15。默认 7K 在 399 张真实谱、8,453 段上保留原标签、family、confidence、次候选、BPM 和整谱决定，只延续已有的五处显示首尾覆盖修复。见 [正式入口对照](results/public-runtime-parity-r1/REPORT.json)、[默认保留检查](results/public-default7-preservation-r1/REPORT.json)。

两处检查失败没有隐藏：粗层严格逐位比较暴露了独立/合并 GEMM 批次的 1e−15 量级舍入差，所有硬决定保持不变，已做实际复现并单独记录数值容差；另一处是 Python 多标签向量的字典序与 API 按支持排序不同，修正的是检查器，而非把 API 排序改错。见 [批次复现](results/coarse-supported-all-r1/batching-roundoff.json)、[完整原对照](results/coarse-supported-all-r1/raw-control-equivalence.json)。

后续最有价值的补充是独立的 7K 区间和原生 6K 形态标注，而不是再次把有限阈值池扩成更多组合。当前采用的输出、权重与证据含义见 [库使用说明](../../README.md)。
