# 保留原专家，让修正进入分段、门控和聚合的同一条链

固定原边界的研究没有检验原生分段耦合。邻接修正与中性手修正都已经给出反例：表示更符合定义，固定旧阈值重新分段却可能更差。因此下一项实验不再把“同一旧边界上的新特征”当成完整升级。

## 比较什么

`native.cjs` 使用完整原引擎：原生变化点、56 项表示、RC/LN 专家、规则特例与 Break 门控。既有专家系数作为固定先验，**不把这个实验说成重新训练过全部原模型系数**。相同条件下的从当前数据重拟合结果另由 MIL 实验给出；历史模型的训练暴露未知。

逐项处理面积、头部邻接、同刻尾/头、拍长相位、无头持键窗口、中性手、短区间覆盖和分段归一化，并比较组合。`logical_neutral` 在本实验中具体包含五项 `logical`、中性手和区间覆盖，完整清单见缓存 specification。Release isolation 的 20/40/80 ms 在同一方案内部选择，不按外层成绩挑一个尺度。变换域归一化是另一种分段特征权重方案，不预先保证收益。

所有表示都重新运行自己的原生分段，不能偷偷继续使用原边界。缓存只依赖谱面事件，不使用目标标签；原默认配置的 399 条输出与已有完整原预测缓存比较。

## 怎样联调

同时选择：

- 最小段长 1.5/3/6 秒、变化点绝对 prominence 0.025/0.05/0.1；
- LN 门控比例 0.35/0.45/0.55，原专家决策或规则混合；
- 原显示平滑或保留原子段落证据的策略；
- 在所选显示策略之后，可选的相对负荷 Break 门控；
- 原聚合、修正分母的硬标签聚合或完整分布聚合；
- 负荷/集中度加权、主导比例、Mix 占比、第二类型相对比例、双标签上限、RC/LN 家族界限；
- 分布聚合的最低具体类型证据与段间多样性门槛。

每项消融使用相同的 **8,192 项不重复联合候选预算**。先包含全部原生分段×局部门控×显示×相对负荷门控元组，再用固定种子的联合 Sobol 候选补足；不按局部准确率先淘汰候选。这不是全部连续参数的全局最优或穷尽笛卡尔积。特征窗长 1 秒、步长 250 ms 和相对 prominence 0.35 固定；这个范围必须随结果一并报告。

除逐项表示消融，还在完整表示上分别限制聚合方式，并对分布聚合去掉集中度、负荷与段间多样性，各自重新选择其余参数。具体空间、强制种子与候选表由 `native_search.py` 保存。

类型定义还明确将 Vibro 排除在 Mix/Hybrid 的普通类型计数之外。新 normalized/soft 路径遵守这个排除；历史 legacy 路径保留原行为作为对照。另加 `full_share_only`（只改分母、仍计 Vibro）和 `full_soft_include_vibro`，不把计数修正的影响冒称为纯粹的置信度加权收益。

仍用六个外层歌曲组折，每折留一张精标谱；内层目标仍为整谱 17 类 macro-F1 与按谱等权分段准确率的平均。固定专家候选没有需要在内层训练的监督系数，所以合并内层验证预测等于这些候选在外层训练组上的预测；阈值和策略只看这些内层数据。每张物理重复文件的总权重为 1。所有选择先保存，再打开该方案的外层输出。

## 指标与证据必须同义

原 `confidence` 是决策分数，不是经验正确概率。研究接口提供归一的**条件决策支持**：明确拒绝 wildcard 时移除被拒绝的 wildcard 质量；Break 门控通过时使用 Break 单位质量。该分布与输出主标签一致，但仍不声称已校准。

`evidence.cjs` 的分布路径用真实时长和同一组权重积累各类型及家族证据。`Σp²` 是集中度；`H(平均分布)−平均H(局部分布)` 是段间多样性。三个段落都无法区分三种类型，与三个段落各自明确属于不同类型，不应自动得到同样的 Mix 证据。证据不足时允许空标签，不强制补一个类别。

显示合并只组合相邻同类段，并保留原子贡献。测试检查细分同一恒定段、合并显示段之后，全谱组成及段间多样性不变。原平滑会继承第一段的分数、桥接短 Break，作为历史对照保留，不将其分数复制问题藏在新“概率”字段里。

JS 的实际消费入口是 `native-policy.cjs`。Python 的向量化评分与它比较了完整门控、标签、组成和多样性；不会只验证另一个 Python 实现。协议在评分前嵌入本轮实际研究模块源码，避免将尚未提交的新代码冒称为某个旧 Git commit 的内容。

### 镜像群平均的匹配对照

中性手修正与原先验的特征分布不完全相同。另设一个不同方向：原谱和物理镜像使用相同原生参数，在两者边界并集上平均决策分布。交换两视图不改变结果，因此整条概率曲线严格镜像不变；无需先把旧专家输入改成一种新分布。它的代价是双次推理。

额外的三组对照固定为分布聚合与保留原子证据：原输入、只修中性手、原输入的镜像群平均。各组仍重新选择相同的其余参数。局部 Break 是聚合资格门控，即使其支持分布还含细类残差也不参与全谱投票；否则极长的休息段会用微小残差压过真实难段。镜像分歧作为描述量保留，不冒称正确概率。

## 仍属于后续问题的内容

本项不包含新 Release 连续几何的模型增益，也不包含 4K 重训或 6K 真实准确率。它先解决已被反例证明的原生流程耦合。Release 的独立特征诊断与 4K/6K 的标签含义分别记录，不能把物理不变量或投影代理成绩写成玩家键型准确率。
