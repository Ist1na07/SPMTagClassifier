# 原权重与重新拟合基线的边界

归档来自插件 v1.2.0 的完整引擎，含两个 56 项 softmax 专家：RC 七类、LN 六类；Vibro 与 wildcard 还有规则特例，Break 主要由启发式门控。训练来源没有跟在模型中保存：模型只有类别、均值/标准差、权重、偏置及版本，缺少训练 UID、划分和配置。

本轮进一步只读检查了同一 SPM 工作区的历史 `TagClassifier_Eta/tagclassifier`。其中 `scripts/trainModel.ts` 与 README 描述：从单标签整谱抽取段落标签，加入六张精标谱的主标签，以三倍/五倍权重训练；分段旋钮也使用六谱调优。这个历史实现与归档具有相同的 56 项与双专家结构，**但其现存模型数值与归档不完全一致**。直接结构比较和模型/scaler 数值定位未找到完全相同的保存模型，不能据此声称已定位归档权重的精确训练批次。

因此，固定原权重的 Native 校准，以及把原模型用作先验的 MIL 对照，仍是已有模型在已见研究资料上的回顾性比较。外层未参与本轮配置选择，不等于已经证明它们未参与原模型或原启发式的发展。冻结先验的成绩不能冒充双方训练材料相同的泛化比较。

另一个必须补齐的对照是**原结构冷启动重拟合**，而非“原56项输入一个新的平面16类头”。`family.py` 因而保留原 RC/LN 路由、规则覆盖、wildcard 处理、低负荷 Break 和显示策略，让两个专家权重可替换。用归档权重消费新提取的规则/门控输入，在 399 条记录上复现了原始逐段标签、平滑区间、家族及置信分数。

后续只用各训练折重新估计专家的标准化与权重，再将其正则、强弱权重、家族门控、规则混合及最终聚合一同选择。这既保留当前算法的真实归纳偏置，也不把未知历史的权重当成干净训练对照。启发式结构本身仍属于过去已经研究过的数据上的设计，结论按回顾性分组验证报告。

历史目录只读，未改动或复制其数据、设置与训练输出；本项目的重新实现与缓存独立保存。

## 相同弱训练集上的人工暴露诊断

`results/family-exposure-r1/` 固定同一批 349 条弱整谱（与全部六个人工歌曲组不重叠）、原结构/边界及历史式配置，只改变是否把当前人工谱提供给拟合。500 轮 GD 的六谱训练集重代入为 67.79%，逐张留出为 51.47%；对同一标量目标充分优化后，分别为 73.74% 与 49.09%。充分优化相对 GD 的留一差值为 −2.39 个百分点，六谱成对区间［−7.31, +2.61］。

这个控制显示当前资料上很大的人工暴露差距；它没有定位归档的精确训练批次，也没有把重代入分数当成验证提升。冷启动分数与旧先验相差较大，不能全部归因于新特征不符合手感或没有联调。接下来优先检验保留成熟先验、限制流程更新容量，而不是用更宽的自由头掩盖标注支持不足。
