# 拆开组合退化，再限制最终候选的语义

原生 25 项消融完成后，完整组合的分段按谱准确率为 62.12%，原固定算法为 69.59%；逻辑修正＋中性手＋覆盖为 69.72%。因此继续研究组合中的归一化与 Release 替换，而不以最高的外层点估计选发布方案。

源代码核对很重要：`logical_release_*` 实际已经包含中性手和覆盖。因此已有三个条件为：逻辑/中性手/覆盖、再加 Release、再加 Release 与变换域归一化。唯一缺少的因子格是**只加变换域归一化**。增加 `logical_neutral_scale`，仍用同样的原生边界/门控空间和 8,192 项联合预算，补齐这一个格；其余三个格直接使用有效的已有重调结果。Release 的三个尺度始终在内层选择。

另建一个明确的修复候选池：逻辑五修正、中性手和覆盖必选；Release 替换与变换域归一化可选，形成八个源表示。显示保留原子证据；聚合只能是同分母 normalized 或完整分布 soft，Vibro 不充当 Mix 的普通第三类。旧分母和继承首段分数只作历史对照，不能因为某折分高就作为修复算法重新发布。

修复池也先保存全部候选与每折内层选择，再生成其外层输出；不在得到各外层方案成绩后挑一个最好的方案。所有原生分段、局部门控和两种有效聚合方式的元组都有强制种子，其余由相同种子的联合 Sobol 预算补足。模型系数仍冻结，训练暴露仍未知；原结构冷启动实验另行完成。这个后续研究由已观察到的退化触发，属于回顾性开发验证。
