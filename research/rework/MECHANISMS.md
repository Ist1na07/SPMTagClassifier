# 先弄清每个量实际测到了什么

## 原 tailIndependence 实际主要在数同步面尾

原实现查找 `allEvents` 中时刻不早于当前面尾的第一个事件，比较该事件与面尾的轨道是否不同。**当前面尾自己就在这个集合里**。按源代码的稳定排序，正常正时长 LN 的尾先于同刻新头进入事件列表：

- 只有一个面尾在该时刻：查找命中自己，结果必为 0，即使此面尾与所有头都相隔很远。
- 同刻有 n 个不同轨道的面尾：所有查找命中同一个最早插入的面尾；其中 n−1 个轨道不同，结果为 `(n−1)/n`。

它因此可间接编码同步面尾大小，却不能解释成“释放时序独立性”。原模型能利用这个相关量，并不意味着量的名字或玩家解释正确。用真正的独立性替换后，固定旧系数发生变化也不能说明替代特征无效。重训与原表示对照缺一不可。

`release_isolation` 目前用“离最近任意轨道头超过 40 ms 的尾比例”作探针。40 ms 还不是面向本集拟合后的尺度。连续的尾→头、尾→尾距离、节拍归一距离和持键状态值得比单一阈值更优先研究。

## 特征与分段耦合，合理修正未必带来同向输出

头部邻接统计应跨过纯面尾行。固定原边界，修正后六谱准确率为 69.575%，高于原 68.921%；同时让该修改进入变化点检测，则降为 67.049%。下一步需要联调边界尺度与头部，而不是撤回数学修正或把固定系数的下降写成最终否定结论。

原分段归一化对 NPS、jackSpeedBpm、cutDemand、tailRate 先作 log 变换，却仍用原值的分位距作分母。若意图是对变换后的量作稳健标准化，分母也应在变换域中计算。两者相当于不同的特征权重：例如 NPS 的实际权重被强烈压低。`transformed_scale` 探针恢复同域分位距，固定旧分段阈值后准确率为 68.080%，不能直接作为上线改进；固定原边界时分类完全不变，符合该处理只作用于分段的预期。

## 原聚合的 share 不是一个归一组成

分子是 `时长 × max(0.4, confidence)`，分母却是未加权时长。share 之和通常不等于 1，变化的不只是各类型相对证据：统一降低所有 confidence 也会改掉 Mix 判定。

精确反例：三个 RC 类型时长分别为 60%、20%、20%。confidence 均为 1 时判为第一种；均改为 0.4 后，原实现判为 RC Mix。归一加权时长保持 60/20/20 组成，就不会发生这个变化。`weighted_shares` 有对应测试；其余参数仍需重选，不能只改分母后假定最优阈值原封不动。

## 数据的独立支持远少于记录数

7K 整谱有效部分为 349 条记录、185 个歌曲/谱面组。anchor 的 6 条记录来自 **1 个组**，LN wildcard 的 3 条也来自 **1 个组**；vibro 有 5 条、2 个组。旧固定划分的训练部分没有 anchor；测试部分没有 inverse、anchor、vibro、LN wildcard。不能用总记录数掩盖这些类别的有效证据量。

两份标注引用 `bm_0153.osu`，分别为 Release 和 Coordination+Release。这不是可以无条件合并的真值。新实验保留两份意见，但每份权重为 1/2，让同一物理文件总权重为 1；另一对相同 Hybrid 标注也作相同处理。

## 4K/6K 的类别语义不能只按名称硬对齐

本地 4K 的 Stamina 子集 296 条中，293 条明确细分为 jumpstream/handstream（其余 3 条 Unsigned）。这说明**该数据集的 Stamina 几乎是多押流样本桶**，不能据它推出“任意长时间高负荷都是 Stamina”已获验证。Speed 子集主要是单押 stream，Tech 也含 jack-tech 和 stream-tech；这些标签存在结构与手感的交叉。

7K Dense/Fast Chordstream 与这个 4K Stamina 桶有结构上的对应理由，但仍须在迁移实验中检验；4K `stamina` 和一般语言的“耐力压力”必须分开。6K 没有键型真值，移去 7K 中键或把 4K 放入六键槽位，只能测试这些投影及标签映射的条件，不会自动证明真实 6K 玩家分类准确。

## 原难度引擎提供一个值得检验的机制表示

插件 v1.2.0 的 `spm_algorithm.js:computeRbar` 同时使用尾→下一事件间隔、尾→尾序列、同手释放次序、其他手指持键与相邻指协调成本，明显比“LN 时长方差”更贴近文档对 Release 的描述。它的参数是既有**难度**模型先验，并非本项目已经拟合好的分类特征。下一阶段可比较固定 Rbar 表示、简单连续释放几何和原完整 56 项，而不把预训练难度系数当作当前标签数据证明。

### 头部采样的 Rbar 仍会漏掉真实的独立释放事件

进一步沿着 `buildBatch` 与 `computeRbar` 读取可见，尾被映射到不早于它的第一个**头部行**，释放区间再散布到 `[ceil(尾), ceil(下一事件))` 的头行。该区间没有头时，散布可以为空。

精确例子：0 ms 按住一列，500 ms 放开，1000 ms 在另一列打击。500 ms 的释放距任何头都为 500 ms，但原 Rbar 的三个汇总量全为 0。这并不把只有一条 LN 的谱面标成 Release 整谱，而是证明 **Rbar=0 不能解释成没有独立释放**。对已经采样成零的曲线做时长积分也不能恢复遗漏事件。反例在 `release-geometry.test.cjs` 实际执行。

更强的序列例子在 0 ms 按下三根同手手指，1000/1125/1250 ms 按非单调指序释放，2000 ms 才有下一头。真实存在连续的独立释放与同手次序，采样 Rbar 仍全零；事件几何保留了它们。这里检验的是表示的可观察性，不把合成动作当作真人整谱标签。

`release-geometry.cjs` 因而直接以尾事件测量连续的头部隔离、同指恢复间隔、尾部异步、时序变化、释放前其他指持键、同手释放次序与同步宽度。尺度使用当前四分之一拍，缺少 timing point 时由事件间距推断；只有事件率随倍速改变，其余时序比例保持不变。轨道占比和持键分母使用真实 K，7K 中键不硬分配给一只手。4/6/7K 的镜像、倍速、全指同步释放及同刻新头反例均有测试。

这些是九项可解释测量，不是九项已经证明有效的分类特征。精标 Release 只有 DS 的三个区间和 EE 的两个区间；不能把总精标六谱写成六个独立的 Release 阳性来源。额外的预测价值先用明确 LN 细标签中的整谱 Release 印象任务检验，弱整谱标签不复制到局部。

## 相同的组成熵，不等于相同的 Mix 证据

两种类型各占 50% 时，全谱组成熵为 1 bit。但它有两种完全不同的来源：

1. 每段都输出 50/50：局部分类器不能区分这两个类型，段间没有区别。
2. 一半段落确定为 A，另一半确定为 B：段间存在真实的类型变化证据。

`H(加权平均 p)−加权平均 H(p)` 在前者为 0、后者为 1 bit。这是段落索引与类别抽样之间的互信息，也就是该组分布的加权 Jensen–Shannon 散度。它描述“段间类型分化”，而不是经验正确率；细分不出短时交替的段落仍可能低估真实分化。保留局部熵与段间分化两个量，比仅用平均分布的熵更能分清未知与多样。是否改善当前标签集，仍需同等预算重拟合对照。

## 组成归一化还必须保留“确有有效段落”的约束

第一版 MIL 在条件化非 Break 概率时遗漏了这个约束。单段 `P(Break)=.99`、`P(Chordjack)=.009`、其余细类合计 .001，条件化后 Chordjack 占 90%，整谱头便可自信报 Chordjack；整谱损失对该 Break logit 的梯度却为零。这两个反例先作为失败测试保留，再修正，原探索在外层评分前停止。

完全取消非 Break 归一化也不合适：短难段加长休息，仍可能有明确的整谱键型。r2 保留条件组成，但把非空整谱标签同时作为“至少存在一个有效段落”的 max-MIL 观测；`max_j P(该段非 Break)` 是至少一段非 Break 概率的保守下界，不需要假定段落独立。各段主标签若仍全部为 Break，整谱就返回空集，不用 argmax 伪造一个细类。这是对监督和实际输出含义的修正，不是通过换评价口径挽救模型分数。

## 方法依据

- [Ilse et al., 2018](https://proceedings.mlr.press/v80/ilse18a.html)：整包标签与实例标签是不同监督层级，包级损失可以通过可微聚合优化。本项目使用具名键型的受约束组成聚合，不直接照搬自由注意力实例打分。
- [Guo et al., 2017](https://proceedings.mlr.press/v70/guo17a.html)：模型分数的集中程度与经验正确率是两件事。因此本轮把 `Σp²` 称为集中度，并通过单独加权消融判断作用；校准的结论需来自未用于拟合/选择的预测。
