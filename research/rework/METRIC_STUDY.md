# 同时校准分段度量，而不是只调峰值阈值

四格实验将一部分退化定位到分段信号的相对权重。`metric.cjs` 在旧/同域规范化信号间作低容量收缩，强度 0/0.05/0.2/1 与 Release 不替换或 20/40/80 ms 的尺度构成 16 个表示。只有分段度量改变；原专家、规则、特征窗及时间步均保持其已声明条件。

16 个源都含逻辑五修正、中性手和区间覆盖。候选联合选择表示、九种边界、六种 LN/规则设置、相对负荷 Break 门控、normalized/soft 聚合及全部既有聚合参数；保留原子证据，Vibro 不充当 Mix 普通第三类。`metric_repaired` 是预定主候选池，不在看到外层结果后从几个消融中挑赢家。

每组 16,384 项不重复联合候选：覆盖全部源×边界×局部门控×负荷门控×有效聚合方式的种子，再用固定种子的联合 Sobol 预算补足。这是同预算比较，不是穷尽笛卡尔积。去 Release、固定旧度量、固定同域度量、硬/分布聚合、去负荷/集中度/多样性各自重选其余参数；另有相同有效消费策略的原表示与固定逻辑表示对照。

全部中间表示已经从 399 条记录无标签提取；端点复用已验证缓存。实际源参数、缓存生产源码、候选、内层选择与外层输出一同保存。冻结候选可以预先计算各记录的输出与指标矩阵，但每个外层选择只读取自己的训练组/五张训练精标谱。测试直接改变该折的外层标签与指标，其选择不变。所有选择属于已有资料上的回顾性开发验证，原专家历史暴露未知。

复现入口为 `native_metric_search.py`。本阶段不宣称冷启动重训原生专家；冷启动原结构及固定弱训练集的人工暴露诊断另列。最终采用的表示强度由内层目标决定，不能用外层最优点回填配置。
