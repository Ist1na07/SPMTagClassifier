# 真人对照指向两个缺口：动作解释随速度变化，主要印象依赖压力背景

原话、条件和不确定性分别保存在 `annotations-r1.json`、`annotations-r2.json`。它们用于建模和反例检查；这些主动构造的谱不进入随机泛化准确率。

## 同一列顺序不能一直叫 Speed

固定7K、OD8、不用DT，同一 `[0,1,5,6]` 顺序持续约8秒：

| 总物量速率 | 用户感知 | stable / modern 整谱输出 |
|---|---|---|
| 16 notes/s | Speed | Speed / Speed |
| 24 notes/s | Tech | Speed / Speed |
| 32 notes/s | Tech/Minijack | Speed / Speed |
| 48 notes/s | (Vibro)Minijack/Anchor | Speed / Speed |

斜杠的组合/备选含义尚未进一步细分，不编造概率或强制单主类。C48每个活跃列物量相同；因此“某一列物量特别集中”不能作为这类高速度 Anchor 感知的必要条件。应描述持续同手二指动作与重复间隔，而非把直方图集中度换一个阈值。

第一批A01的变速探针还同时改变谱长、BPM时标及评分器的有效判定条件，不能当作本表的固定OD密度实验。

## 相同局部动作，在更难的背景中成为休息

CTX-L/H 的9–17秒目标头时间和列逐项相同。用户确认：H的**目标段**是Break，整谱是Dense CS（bracket）；17秒后恢复多押的段落不是Break。L整谱一直低密度，目标只能勉强归为低置信Dense CS或Fast CS；“并没有能归类的”应保留为类别体系不完全匹配，而非高置信训练标签。

实际自动分段：

- stable把H中间段8,312.5–15,812.5ms判为Speed；modern判为Break。
- 两者整谱均为Dense CS。modern已经识别到大部分休息段，但两条边界分别比真实9,000/17,000ms提前687.5/1,187.5ms，仍漏掉目标末尾1,187.5ms。
- L被两者高层决策归为Speed，尚未表达用户所说的低置信类别不匹配。

因此不能宣称“完全没有上下文机制”，也不能以整谱tag正确掩盖局部类型与边界问题。代码里的强制单目标区间诊断只用于查看特征，不是上述自动路径。

## B01/B02：先修压力路由，再谈Release专家

B对保持LN头、总持键面积、谱面终点相同，只改变放手时间。用户给B01 Break、B02 Release。实际stable/modern却都整谱无tag，所有分段Break。

错误链有两层：

1. 旧 `markBreaks` 用头NPS、相对头密度和间隔预标Break；`classifySegments` 遇Break预标或无头行直接返回。B02的释放证据在专家之前就被截断。只增加Release头特征不能纠正这条路径。
2. 旧 `heldOtherAtTail` 在释放前计数，把同一时刻一起放掉的其他手指也算进去，B01反而为0.8333，B02为0.4167。它能表达“释放前其他指按住”，但不能替代“放手后仍须维持的约束”。

新 `release-actions.cjs` 因而同时记录释放指与保留指。候选连续量对保留指的已按时间a、剩余时间b采用 `(1-exp(-a/τ))*(1-exp(-b/τ))`；同步放手为零，微小错位连续地接近零，避免将1微秒错位变成有限难度跳变。精确事件组只用于诊断，正的保留指值不是一个硬Release规则。

97条明确LN整谱的完整联调消融已完成，见 [报告](results/release-feature-r1/REPORT.md)。它检验整谱Release证据，不提供局部Release准确率，更不能据此宣布17类分类器已提升。释放尺度的条件profile还触及网格边界，另做内层边界/极限形状实验，不靠事后外层成绩选择尺度。

## 下一候选：软压力门控与动作原型分工

优先实现下面一条统一路径，而不是继续叠硬补丁：

1. **动作时间轴保留头与尾。** 共享已有准备上下文；头部困难复用SPMRating，放手约束补充其头行采样没有覆盖的时间。静态持键是动作条件，不自动成为有效LN压力。
2. **Break是联合学习的相对压力状态。** 同时输入绝对动作速率/困难和相对全谱难段的压力；不先用头NPS把Release或无头区间不可逆截断。先比较原分段与包含尾动作的多尺度区间，避免同时改变全部假设后无法归因。
3. **键型头看有序动作与速度的交互。** 同手滚动、二指重复和跨手顺序分别表示；可复用SPMRating已有连续手部contact/eligible/coactive，避免再造一个固定毫秒“近似双押”分类规则。C16–C48提供方向约束，不足以拟合通用速度边界。
4. **困难聚合与类型置信分开。** 复杂但困难的段落仍能影响主要印象；类别匹配弱可以表现为低置信组合，不因置信较低就自动被排除。整谱概率由完整手工tag监督，以低概率负例的低连续loss表达弱印象。

验证必须分别重调压力项、动作项、困难聚合、置信调制的有效参数，再做交互比较；同时报告整谱集合匹配、逐类P/R/F1和连续PR，局部边界与Break另列。4K仍对齐其五桶真值，6K物理外推不能冒充真人分类性能。
