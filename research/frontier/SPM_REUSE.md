# SPMRating：先共享计算，再检验哪些量有分类价值

研究固定使用 [SPMRating v1.2.0](https://github.com/Ist1na07/SPMRating/tree/v1.2.0)，实际 commit `a914a405d8e9a77f94c0518567c37511b0b7ac05`。读取的是该 tag 的实现，不以默认分支 README 代替版本接口。上游为 MIT；本轮没有修改上游仓库。

## 已有评分结果可以直接复用

`rating_bridge.py` 的 `RatingEvidence` 接受评分器已经返回的 `include_curve` 结果，检查原生键数、rate、时间轴和字段长度，再读取任意半开区间的统计量；**不会再次调用评分器**。它复制输入数组，不改变评分方的数据。

```python
# result 是分析器在同一次流程中已算出的 SPMRating include_curve 结果。
evidence = RatingEvidence(result, expected_keys=7, expected_rate=1.)
section = evidence.window(9000, 17000)
```

需要保留四项含义：

- 时间是变速后的毫秒。`query` 是**头部行采样**，不是均匀时间格，也不是每个放手都有观测。`rowMean` 不能解释为时长平均困难。
- 无头窗口的字段为 `None`，不能补成零难度。399条记录的8,453个原始区间中，每个模型均有37个这样的窗口。
- SPMRating 内部把4K放在七列框架的 `[1,2,4,5]`，6K放在 `[0,1,2,4,5,6]`。原生键数必须另外保留，空出的列不是玩家的空键或7K中键。
- 上游对小数源时钟有相位平均。公共曲线桥接可消费其结果；下面的私有组件探针只支持原生时钟，并明确拒绝相位平均路径。

## 组件已做到同一次预测中观测，但还是研究接口

`capture_native` 在私有函数命名空间中观察原 `Engine.predict` 传给 `model.combine` 的数组，不改模块全局、不改上游源码。两次镜像视图属于上游同一次预测；观测组件不额外评分。返回的组件是镜像视图的均值，不是能相加还原最终困难的归因。

这是固定版本的研究探针，不能当作稳定公共 API。未来联合分析器可以先消费已有公共曲线；若需要组件，应由共享评分调用显式返回这些字段，而不是长期依赖私有函数代码结构。接入 Node 产品的接口、序列化和逐值验证尚未完成。

实际验证保存在 `results/annotation-probe-r1/integration-audit.json`：两个模型、4K/6K、rate1/1.5及六张真实7K的曲线/分数与公共接口逐值相同；小数源时钟走拒绝路径而非伪装为平均。第一批16个构造谱/变速观测也与已保存公共结果完全一致。公共桥接另有时间轴、缺失值和输入不变单测。

全量缓存 `.cache/frontier-rating-r1/` 覆盖399条记录、397个物理源、detail/compact两个模型，共794次实际评分、798条记录输出。重复物理源复用曲线，不因标签记录重复而重新评分。全部源通过原生时钟预检；没有静默跳过谱面。生产 Node 库未增加 Python/NumPy 依赖。

## 难度量不是现成的键型概率

用户把 B01 判为 Break、B02 判为 Release，但 detail 的整谱原始难度分别为2.1981、2.1564；Rbar最大值分别为0.8041、0.7248。这个对照说明不能把总分或 Rbar 单调映射成 Release 置信度，并不以键型标签代替难度真值。

固定OD8、无DT的第二批对照中，detail 的局部需求随 C16/C24/C32/C48 由5.678、9.440、13.689增到19.476，能提供绝对速度/困难轴，但仍不等于用户的类别转变。CTX-L/H目标头相同，目标需求与全谱头行P90之比分别约0.999、0.455；这是相对压力的可用线索，尚未校准为 Break 概率。局部需求本身也随上下文变化，不能把它当成只依赖目标内事件的独立量。

已完成的97条明确LN整谱 Release 研究同时比较总需求、全组件、旧释放几何、新保留指几何及两种组件拼接，并完整联调有效参数。新几何单独使用有硬指标增益，拼接组件却退步，且主要成对区间均跨零，见 [完整报告](results/release-feature-r1/REPORT.md)。因此首选保留**共享困难轴与动作结构的分工**，不直接把所有组件堆进分类头。

SPMRating 参数是冻结的辅助难度先验，其历史训练可能接触同批谱面。本轮结果按回顾性分组评价报告，不称为重新按分类折训练的干净先验。
