# 下一轮：找到可辨识的键型模型，而不是继续扩大旧策略池

## 用户明确的目标（2026-11-01）

- 整谱 tag 对齐**玩家主要感知到的键型**；玩家更关注困难段落。不拆成“出现过”和“主要负担”两套产品输出。
- 现有类别来自标准赛图 slot。复杂段落优先用**多个简单类别的偏低置信度组合**表达，不强行增加硬类别。
- 误报和漏报影响大致等同，**误报略好于漏报**。不能把只提高精确率当作完成任务。
- 7K 整谱由用户手工尽量完整标注，直接对齐。未标 Release 表示它未占主要感受；超过应输出阈值就算误报。低占比、低置信的预测应产生较低连续 loss，而非同等的硬错误惩罚。

v1.2.1 的交付已完成；它没有确定模型的性能上限。本目录记录新的研究，不修改已发布 tag 或原实验结果。

## 已经找到的搜索缺口

`landscape_audit.py` 检查了已保存的六折 geometry3/LN-protected **内层预测**。原实验确实把全部 31 个头选择与同一 512 策略池交叉，但 512 策略只是有限设计，不是全部后处理坐标的笛卡尔积。

在六折各自选中的策略处，13 个可变后处理坐标**全部没有保持其他坐标不变的对照点**。例如 confidencePower 在整个池里也只有一组匹配上下文，minEvidence 和 minimumDiversity 完全没有。不能从这一设计判断选中点附近的曲率或稳定性；参数取值跨折改变，也不自动说明优化器出了问题。

`local_slices.py` 已对全部六折补充固定头、固定其他坐标的切片，使用原实际内层留出预测，检查重算基准与原选择一致到 1e−12。每折 39 个切片条目对应 25 个不同配置，未新增系数拟合，familyThresholds 的上下阈值分别变化。六折都找到比旧池赢家更好的邻点：旧联合分数增加约 0.09～0.21 个百分点。这说明原池赢家甚至尚未达到所检验坐标邻域的局部最优；这些数字是**内层诊断**，不是新泛化成绩。

完整结果在 `results/diagnosis-r1/`、`results/local-slices-outer*-r1/`。同标量分数但不同预测单独记账；完全相同的预测与相同分段准确率也不被误称为完整分段预测相同。

## 建模方向：简单原型的软混合，由困难感知驱动整谱印象

首选先做低容量、可解释的多尺度事件模型，而不是直接堆深度网络。当前的关键假设是：标准 slot 对应不同物理结构的原型，复杂段落是软混合；玩家整谱印象取决于这些结构在困难段落中的突出程度。

1. **保留顺序和动作。** 用真实手指的头、尾、持键转移和时间间隔构造事件结构，比较短 run、跨手轮换、同手顺序、释放与新头竞争等多尺度量。镜像等价与绝对速度的实际影响分开处理，不把变速后标签不变写成先验。
2. **将组合与可信程度分开。** 简单原型的混合权重解释组成；拟合残差、预测分歧和真人标注校准解释置信。高 softmax 集中度不自动等于“正确”，低置信复杂段不自动等于“无贡献”。
3. **独立建模困难贡献。** 头部、持键和释放都可能构成困难，不能只看头速率。聚合比较时长平均、困难加权、尾部分位/持续难段贡献，并控制短暂离群事件支配整谱的风险。
4. **检验置信度加权是否伤害目标。** 同一批低置信复杂段可能最困难。必须分别消融困难项与置信项，不能把二者揉成一个无法归因的权重。

这些是待检验假设。最小对照谱用来让用户确定“应有区别”和“应当保留的组合”；随机抽取、按歌曲隔离的真实谱用于测量改进，二者不混为准确率测试。

4K 保留其五桶监督的真实含义；7K 使用标准原型及组合；6K 保持真实六列上的共同物理表示，直到有真人证据才扩张细分类。

## 连续 loss 必须符合已确认的标注口径

整谱标签是玩家主要印象的目标，而不是“任意一处存在该结构”。对某个未标类别，若模型只给出很低的整谱印象概率 p，负例交叉熵 `−log(1−p)` 本来就很小；高置信误报则受到较大惩罚。正例使用 `−log(p)`，防止所有输出一起缩到零。

这里的 p 必须是面向整谱印象学习或校准的量，不把局部 affinity、归一组成或“集中度”直接当作已校准概率。尤其不采用“把模型自己预测的低置信度乘到自身 loss 上”的自由机制，以免靠压低置信逃避错误。

学习连续证据与选择输出阈值是两个相互关联但不同的问题；用实际内层留出分数联合评估，不把默认 0.5 当成定义。稀有类别的阈值应与共享/家族收缩对照，不能给只有一两个歌曲组的类别随意增加独立参数。参见 [scikit-learn 的阈值调节说明](https://scikit-learn.org/stable/modules/classification_threshold.html)。

## 参数在“平地”上时，先判断是哪一种平地

| 观测 | 需要的证据与处理 |
|---|---|
| 参数在当前分支不生效 | 例如 normalized 下的 soft 专用参数：标记为不适用并消除重复配置，不优化它 |
| 不同参数给出同一预测，但连续分数在变 | 沿实际预测断点检查硬指标平台，同时看连续 loss、PR 曲线和到断点的距离 |
| 参数互相补偿 | 补匹配的一维/二维切片、条件重优化及预测 Jacobian；能合并的自由度重参数化 |
| 分数不变但错误换了对象 | 比较逐谱、逐类预测与 TP/FP/FN，不能只看一个平均分 |
| 参数跨重采样漂移，预测也漂移 | 对歌曲组重采样，量化预测及 operating point 的不稳定性，再针对分歧补标 |
| 当前数据没有触发相关机制 | 构造最小对照、选取真实近边界段落请用户判断；不靠更密网格创造信息 |

训练目标收敛不等于模型正确，也不等于超参数已定。后续搜索先剔除无效坐标，补全选中点邻域，再进行有交互的块搜索与边界扩展。可用 fANOVA 辅助识别交互，但其代理模型推断不代替实际匹配实验：[Hutter 等，2014](https://proceedings.mlr.press/v32/hutter14.html)。

不是所有参数都应该进入尖锐的井。表现好的宽平台可能更稳健；必须区分无害的等价参数与会让新谱预测翻转的漂移。正则化可以选定代表解，但不能证明数据已经辨识了参数；训练 loss 的曲率与正则项提供的曲率分别记录。

## 评价不再由一个加权平均分概括

对齐旧基线，固定数据、歌曲组和标签含义，同时报告：

- 整谱完整 tag 集合匹配率、逐谱 Jaccard、宏/微/逐类 precision、recall、F1，附每类阳性歌曲组数量。
- 有连续分数时报告逐类 PR/AP 和 operating point；只有硬 tag 的旧保存结果不伪造 AP。
- 分段按谱等权与时长加权结果、困难段表现、边界误差、复杂组合段与 Break 分开报告。
- 有对应真值时检查校准、NLL/Brier；允许备选主类与同时存在的组合属性分别编码。
- 参数、输出和各指标的歌曲组重采样变化；比较多指标 Pareto 前沿，并展示接近对称、略偏召回的取舍，不擅自将用户偏好设成一个很大的召回权重。

新增诊断显示旧候选主要提高整谱 precision，macro recall 几乎未动，见 `results/diagnosis-r1/REPORT.md`。因此不能再把单一 macro-F1 的小幅增加当作主要困难已经解决。

每项候选/消融都重新选择其有效的完整声明参数空间；移除机制后同步移除不生效参数。新搜索方法本身也与旧采样策略比较，使用同一输入、目标和可计量资源。原型、困难聚合、置信权重、连续 loss/阈值与搜索策略分别归因，不能一起替换后只报一个总差。
