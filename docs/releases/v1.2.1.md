# v1.2.1：回炉研究与原生键型分类

本版保留 v1.1.0 / v1.2.0 历史 tag，修正早期研究的联调与归因结论。

## 采用的实现

- **4K**：原生五类模型，同一局部分布用于分段、联合拟合的证据权重和整谱组成。歌曲分组嵌套评价 macro-F1 为 **95.56%**；整谱桶名监督不等于逐段真值。
- **6K**：真实六列上的共同形态表示，结合 4K/7K 监督，不再混合投影专家输出。提供五类粗标签；没有人工六键键型准确率结论。
- **7K 默认**：保留成熟决定，增加 anchor / release 连续几何证据。新指标不硬套旧系数。
- **7K modern**：替换旧扁平研究头，显式运行完整联调后的 LN 小幅更新与 LN 保护门控。该候选整谱 macro-F1 为 54.32%、人工细类分段按谱为 68.75%；原固定算法为 51.98% / 69.59%，不足以替换默认。

## 研究与验证

共同粗层包含 16 项专家控制和四种物理充分条件流程，保存完整内层配置评价、外层模型、逐谱预测和优化状态。相同有效拟合与重复配置单独记账，不当成新增独立证据。LN 头与额外负荷门控分别消融、完整重选，定位了头部负荷门控误删持键/释放段的问题。

最终模型只由实际内层留出预测选择，不从外层挑赢家。完整主研究、负结果、限制和复现入口见 [研究结论](https://github.com/Ist1na07/SPMTagClassifier/blob/v1.2.1/research/rework/CONCLUSIONS.md)。

- 最终原生六键：2,343 张有效真实谱、180,009 窗口、32 张真实镜像检查通过；已知反向 LN 尾按错误拒绝。
- 正式 Node API / 浏览器：27 张真实 4/6/7K 谱完整 JSON 一致，与 Python 消费者的局部支持最大差约 1.45e−15。
- 默认七键：399 张真实谱、8,453 段保留原标签、family、confidence、次候选、BPM 和整谱决定。
- 静态浏览器构建不使用运行时字符串编译；独立安装包、CSP 风格上下文和 TypeScript 声明已检查。

## 接口变化

4K / 6K 的 `overall.tags` 为单一主导粗类，`overall.weights / scores / composition` 均为同一归一组成；6K 不再返回缺少真值支持的七键细类。公开 `stamina` 保留源 jump/handstream 桶的兼容名称，内部 canonical 名称是 `chordstream`。

7K 默认 confidence / scores 与旧权重单位不变。新候选的 confidence 是显示类归一支持，旧 affinity 在 `evidence.legacyConfidence`；权重仍明确保留加权秒数。所有支持都不是经验校准的正确率。

原 `buildCachedMap` 以及 40 项 `buildEvidenceMap` 合同保留；53 项原生粗层窗口从 `debug.windows` 读取，不混用缓存。完整用法见 [README](https://github.com/Ist1na07/SPMTagClassifier/blob/v1.2.1/README.md)。

附件提供 Node 包、可直接引入的浏览器文件及研究源码/证据归档。原谱数据不再分发。
