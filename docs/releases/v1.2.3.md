# SPMTagClassifier v1.2.3 — 同一迭代的统一交付

研究基线为 **v1.1.0**。本轮全部成果均属于 **v1.2 系列**；此前 v1.3.0 是错误编号，已标记归档，不代表新一轮研究。

- 默认 Detailed 恢复较早 R1：相同349条、相同源分组的整谱 OOF P／R／F1／完全匹配率为 **59.03%／53.99%／55.34%／63.83%**，高于扩域 R3 的58.61%／53.09%／54.43%／62.68%。这不是局部成绩；全数据共同配置回放另列，不混作泛化评价。
- 原始 v1.1.0 同口径为55.15%／51.35%／51.98%／57.78%。v1.2.2 仅为实验中的冻结先验／过程对照。

- 更新器兼容已安装误编号 v1.3.0 的插件标记；仍默认 dry-run，应用前备份。npm 用户请显式安装本版本，不依赖自动降版。
- 默认局部分类未改；Tech→Dense CS 等问题和未收敛的反传实验仍如实保留。实时游戏／tosu 尚未验收。

本发布中的研究压缩包聚焦整谱聚合及本次复核；本轮其他研究仍完整保存在仓库 `research/rework`、`research/frontier` 和 `research/overlay-quality`。
