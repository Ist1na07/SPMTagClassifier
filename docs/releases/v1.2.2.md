# v1.2.2 — overlay BPM 与高速段休息误判修补

## 使用

下载 `tag-engine.js`，备份插件原 `tag_engine.js` 后替换同名文件并重新加载 overlay。无需改设置或难度引擎；回退时恢复备份。Node 使用 `spm-tag-classifier-1.2.2.tgz`。本次不改写 v1.2.1。

## 改善与取舍

- 均匀打击行直接测量等效 BPM，修复300→200等网格别名；Jack 保留动作时钟。72个构造节奏／平移／变速对照的错误数值由21处降至0。
- 默认7K不再只因规则高速段略低于整谱物量中位数而标 Break。两条主动选取、按来源歌曲留出的 Speed 摘录主类覆盖79.33%→100%，不是总体准确率。
- 349条整谱标签记录的源分组回顾性评价：macro P/R/F1 55.15/51.35/51.98%→55.07/51.47/52.02%；原六谱局部69.59%→69.41%，其中 DS 留出休息误报4.25秒。保留原聚合策略，未采用召回下降的另一调参方案。
- **Tech→Dense CS 尚未解决。** 完整调参的手部／分段及BPM输入候选未减少该真实错例，不部署这些头。4K/6K保持既有实现，6K没有新增人工准确率结论。

Python回放与公开Node／静态浏览器构建已对齐；原插件渲染器离线检查确认 F02 从 Break 改为 Speed。实时游戏／tosu 链路尚未验收。研究包包含紧凑证据及源代码，数据集、原始谱面与大体积私有中间缓存不随包分发；详见仓库 `research/overlay-quality/CONCLUSIONS.md`。
