# SPMTagClassifier v1.3.0

聚焦 7K 整谱 tag 与 overlay 的负担百分数，保留 v1.2.2 的局部主类和 BPM 修补。

- 多分支原型支持 × 连续时间动作负担；可复用同次 SPMRating Detailed／Compact 原始难度场。无评分输入使用独立联调配置，不重复评分。
- 新百分数参与整谱门控，改进 RC／LN 混合谱识别；百分数不是正确率或时间占比，各分支可重叠。
- 提供默认 dry-run、先备份的插件更新器，接通原始难度、模型切换和显示；`aggregation:'classic'` 可恢复 v1.2.2 整谱策略。
- 原349条、歌曲／重复物理源分组的回顾性对照：macro F1 从52.02%至动作版53.79%、Detailed54.43%、Compact53.67%；整谱完全匹配率从58.07%至62.68%。三个方案的总体 P/R/micro/sample F1 均提高，逐类仍有退步。
- 以上包含验收后明确采用的一阶支持约束，不是新的盲测。原始平方支持、组件和其他失败方案保留在研究记录中；局部反传实验因未完全收敛未采用。
- 411 张输入、三套最终配置的 Python／Node 逐项对照，静态浏览器、类型和实际 overlay 离线检查通过。未进行实时游戏／tosu 验收。Tech→Dense CS 等原局部误判仍可能出现。

安装 npm 资产中的完整包后，按 `docs/perception.md` 运行更新器。单独替换 `tag-engine.js` 不会更新旧 UI 的时间占比含义。旧 release/tag 不改写。
